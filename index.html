01 / Quick start

From folder to first commit

Open a terminal (or Git Bash on Windows), then follow these steps inside your project folder.

01

Install Git

Install Git for your operating system. Then check that it works.

git --version
02

Set your identity

Use the name and email you want attached to your commits.

git config --global user.name "Your Name" git config --global user.email "you@example.com"
03

Go to your project

Navigate into your existing project directory.

cd path/to/your-project
04

Initialize Git

Create a new local repository in this folder.

git init
05

Stage your changes

Stage all current files. Review what will be saved if you like.

git status git add .
06

Make a commit

Create a snapshot with a short, meaningful message.

git commit -m "Initial project commit"
✦
Beginner tip
A commit is a saved snapshot of your project. Commit messages should explain what changed.
02 / The basics

Three ideas to remember

Git gets easier once these building blocks make sense.

📁

Repository

The project folder Git tracks, including its history of commits.

📦

Staging

The changes you select with git add for your next commit.

📸

Commit

A recorded snapshot of staged changes, with a message and author.

03 / Daily rhythm

Your everyday Git workflow

After editing files, repeat this small cycle.

Edit files→ git status→ git add .→ git commit
git status git add . git commit -m "Describe your update" git log --oneline

Want to publish your project online? Create an empty repository on your Git hosting service, then follow its instructions to connect your local repo and push it.
